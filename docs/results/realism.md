# Realism: personas' input compared with real users'

Generated by `python -m vanguard.evaluation realism` from batches `suite-a3-northgate`, `suite-a3-tallowmere`, `suite-a3-willowbrook`, `suite-a3-riverside`.

Pointer share is pointer actions over pointer actions plus key presses. Tab and arrow share and Enter share are over all key presses (repeated keys counted per press, typing one press per character). Persona values use executed actions only. Real users' values are from Reduced A11y-CUA (CC BY 4.0), aggregates only: keyboard-only is compared with blind and low-vision users, unrestricted with sighted users. A11y-CUA's tasks were desktop tasks, not these sites' tasks, so this compares input habits, not performance.
