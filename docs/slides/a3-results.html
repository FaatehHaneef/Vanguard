The audit tool

From a demo to an audit tool

Live view & replay

watch the browser as the characters work; replay any run step by step with the reason for every decision

Findings report

unreached controls, navigation failures, repeated actions, confusing workflows, failed tasks

Failure attribution

site, restriction, agent or infrastructure, with the evidence

Configuration studio

make personas, add any website and its tasks, no code changes

Comparison report

two batches side by side: better, worse, new and resolved failures

Task-level evaluation

scenarios, realism against real users, diversity, verifier precision and recall

Every report states it: simulated users cannot establish accessibility compliance or stand in for people with disabilities.

All of these are in the product today9
