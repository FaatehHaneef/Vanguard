Vanguard

Auditing LLM-simulated users with enforced limits

An AI agent plays a person with limits (a keyboard-only shopper, a screen-reader user) on real websites. Vanguard enforces those limits in code and checks every step for leakage: the agent doing what that person could not.

Syed Muhammad Faateh Haneef (23i-0688) · Abdul Hadi (23i-0676) · Ibrahim Malik (23i-0694)

What was evaluated in A3

  • Simulated-user agent (Gemini 3.6 Flash, forced tool calls): 24 runs, 119 steps
  • Baseline vs ours: limits only in the prompt vs a code-enforced gate
  • Personas: Knock (keyboard-only) and Cog (unrestricted control, scored as if every limit applied)
  • Tasks: Tallowmere "cheapest candle" and Willowbrook "request a callback", 3 repeats each, 12-step cap
  • Leakage checker (deterministic code) validated against 60 human-labelled steps
  • Real browser: Playwright drives Chromium; real key presses and clicks; trusted input events recorded
